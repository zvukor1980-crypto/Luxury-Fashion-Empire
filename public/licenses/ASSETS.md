# Asset provenance
Characters exported from MakeHuman/MPFB core base mesh, game_engine skeleton, and official makehuman_system_assets_cc0 pack. Core assets and system assets explicitly released CC0 in September 2020.
Sources: https://github.com/makehumancommunity/mpfb2 and https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip
Tools: Blender 4.5.3 (GPL), MPFB (GPL). Tools are not bundled in the browser game. Output mesh/textures: CC0.
Hand-authored animations and shape morphs: created for Luxury Fashion Empire.
Three.js: MIT, https://threejs.org/license/ .
